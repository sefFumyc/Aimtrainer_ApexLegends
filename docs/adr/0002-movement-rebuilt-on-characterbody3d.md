# 在 CharacterBody3D 上重建移动模型，不使用引擎的默认加速

移动模型（速度曲线、转向衰减、速度保留率、滑铲、蹲伏、空中控制、速度修正器）是原版最有价值的资产，必须 1:1 保留。Godot 的 `CharacterBody3D` 只提供 `move_and_slide()` 做碰撞求解，`velocity` 完全由脚本写入——因此本项目**自己算速度**（按固定子步做分段线性积分，与原实现同构），`move_and_slide()` 仅承担碰撞、斜坡判定与贴墙滑行求解，不参与加速与摩擦。这样既不丢失原手感，也无需自建碰撞推演。

_否决「移植纯数学 MovementSimulator 并自管碰撞盒推演」——会与引擎产生两套并行的地面判定。否决「用 Godot 内建物理参数（`floor_max_angle`、`motion_mode` 等）替代模型」——直接丢失本项目的核心资产。_
