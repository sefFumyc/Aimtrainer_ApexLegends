# 场地保留圆形边界，遮挡物程序化生成并做成可切换布局

Bot 的「撞墙反向」与「贴墙内拐」依赖**径向**边界判定；原版场地是圆心在原点、半径 1000 的圆形平面（矩形场地是已被推翻的历史方案，见原 ADR-0004 的措辞），因此边界几何保持不变，只把视觉从原版的竞技场看台换成程序化地面与环形围墙。遮挡物由程序化箱体与柱体构成，**参与碰撞且参与视线判定**（不是视觉装饰），并做成三档「场地布局」设置项（空旷 / 少量遮挡 / 多遮挡，默认少量遮挡），同一参数同时驱动 Bot 的「前向探测」阈值。布局生成必须避开玩家与 Bot 的刷新点。

_考虑过搬原版竞技场看台视觉——与本项目目标无关，且是原版独立的 ADR-0028。考虑过缩小半径让靶子更近——会改变原版的命中率与难度手感，属于改写玩法而非复刻。_

勘误（ADR-0031，2026-10-15）：环形围墙已从纯视觉改为**实体**（世界层，参与碰撞与射线），「边界由径向钳制负责」不再是唯一手段、钳制退为兜底；「贴墙内拐」随之退役（贴墙行为交给物理与钳制）。本条开头「Bot 的撞墙反向与贴墙内拐依赖径向边界判定」的理由至此只剩「撞墙反向」一项成立——边界几何仍是圆、半径仍是 1000，口径不变。
