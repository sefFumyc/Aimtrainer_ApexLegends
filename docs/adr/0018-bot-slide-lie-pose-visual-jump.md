# bot 滑铲表现二轮：坐改躺 + 表现层垂直抬升（修订 ADR-0017）

ADR-0017 定稿的坐姿方案实测暴露两个问题：

1. **坐姿不够低**：`Sit_Floor` 上身直立，视觉仍是半身高轮廓——用户观感「坐下太高、不像滑铲」，要求换躺下。
2. **铲跳不真跳**：bot 铲跳只在地面上播放跳跃动画、跳不起来。排查确认 sim 的垂直维度**是完整的**（`_pending_jump` → 滑铲跳分支：垂直 286、重力 790、空中摩擦全套在积分，`_height_v` 正常升到峰值），但场景层 `_apply_motion` 每帧 `global_position.y = 0.0` 硬压、`velocity.y` 恒 0、命中体只算蹲伏压低——**高度在表现层被整个丢弃**。

定稿方案：

- **姿势 = Lie 三件套按段快放**：`Lie_Down` ×4（3.0s → 0.75s 倒平）→ `Lie_Idle` 原速循环 → `Lie_StandUp` ×2.5（2.33s → 0.93s 爬起）。姿势机状态机结构不变（DOWN→SIT→UP、铲跳仍走 Jump_Start→Jump_Idle 过渡，躺姿换坐姿而已）。事实依据：探针实测 Lie 族时长 3.0 / 2.67 / 2.33s，滑铲全程只有 0.35–0.9s，原速播必截断。
- **命中体压深 −50u**：躺姿视觉最高点 ≈20u，72−50=22 的判定轮廓与之贴合；ADR-0017 的 −30u 决策随坐姿一起废止（压低量跟姿势走，不再复用玩家 `CROUCH_HEIGHT`）。继续不旋转：部件盒旋转后头/身判定要重验，收益低。
- **铲跳表现层垂直抬升**：视觉模型、命中体、枪口/曳光起点一起按 sim 跳跃高度（`_height_v`，峰值 = 286² / 2 / 790 ≈ 52u）抬升；接触暗影留在地面；移动碰撞胶囊贴地不动。bot 命中玩家的判定是概率骰、不受枪口高度影响，曳光起点变高纯视觉；命中体跟着跳 = 玩家打空中的 bot 判定随之变高，「所见即所中」保持。`movement.gd` 只加 `jump_height()` 纯读数，移动模型与 bot 决策零改动。
- **滑铲时长保持 0.35–0.9s**：短滑铲（<0.75s）倒地未播完即被打断起身（0.15s blend 兜底，视觉是「倒到一半直接爬起」），实测不满意再调倍速或时长。

_考虑过 `Lie_Pose` 静态贴 + 0.2s blend（任何滑铲时长都完整躺平）——否决：倒下是骨骼插值「飘」过去，没有动作化的倒地曲线；快放的真实动画更像「扑倒滑铲」。考虑过物理真跳（CharacterBody3D 带垂直速度 `move_and_slide`）——否决：物理与 sim 双积分器要同步、滑铲碰撞行为会变，而移动胶囊根本不需要离地，收益为零。考虑过拉长滑铲时长配合原速动画——否决：399 u/s 注入下滑 3 秒横穿半个场。快放倍数 ×4 / ×2.5 与压深 −50 是手感调参起点，实测后可调。_
