# 围墙实体化 + bot 后退推力随离墙余量衰减

两件事一起定（拷问三轮）：① 场地半径 1000 的环形围墙从纯视觉改为**实体**——一个 `StaticBody3D` + 96 个盒形碰撞（段数与 `GROUND_SEGMENTS` 一致，内表面即视觉那个圆），归世界层、与「遮挡物」同性质；② bot 的**后退**分量（前后分量中远离玩家的那一半）随「离墙余量」按比例衰减，余量耗尽即为零；**只在后退方向生效**——前进方向朝玩家、连线天然不出凸圆，且该方向已由「前向探测」+「撞墙反向」管，后退轴才是唯一没有泄压阀的一轴。余量 = 沿后退方向到半径 1000 圆的解析距离 −「体型半径」（bot 的移动胶囊被 `apply_body_radius` 连碰撞形状一起缩放，实际半径就是该项设置）；余量口径用独立常量（初值 60），**不随「场地布局」变**——布局只管侧向的前向探测。

起因是实测 bug：目标距离设大（如 1600）而玩家居场心时，距离需求在几何上不可达，bot 一路满幅按 S 退到边界；而旧实现在 `r ≥ ARENA_RADIUS` 时把本帧输入**整体替换**为「朝圆心」（即「贴墙内拐」），与后退 wish 恰好差 180°——180° 的转向衰减保留率只有 5%，于是每帧「朝内一帧、朝外一帧」对打，速度被绞到近零，观感就是「卡在墙边走不动」。旧实现唯一的边界泄压阀是「撞墙反向」与前向探测，两者翻的都是侧向（`avoidance.dir`），**前后轴没有任何泄压阀**，且 `dir == DIR_NONE` 时侧向也是空操作。

因此「贴墙内拐」与 `_handle_walls` **整体退役**：墙有了实体后，贴墙行为（沿墙切线滑行）交给物理，纯逻辑模型里由仿真自身的径向钳制镜像同一语义。保留的边界机制有三条：`wall_flip` + `on_blocked`（实际位移 < 意图一半即翻侧向，0.3s 提交窗）——它是墙边「滑不动」的兜底（数帧内必有一次侧向翻向）；「躲避」的贴墙守卫——门限从 `ARENA_RADIUS` 重定基到 `ARENA_RADIUS − 体型半径`（墙实体化后 bot 最多到 990，旧门限永不触发 = 墙边躲避白掷并静默重置变向计时器，正是当年加守卫要防的事）；「前向探测」的解析边界臂——`BotAi` 是纯逻辑、GUT 里没有物理墙（ADR-0009），删掉它纯逻辑模型对边界就只剩仿真钳制、失去提前量。ADR-0004 那句「Bot 的撞墙反向与贴墙内拐依赖径向边界判定」至此只剩前一项成立。

墙入世界层的连带效应：玩家开火射线（掩码含世界层）**开始被墙拦**，未命中曳光弹的落点变成墙面命中点（原为固定长度空放）；bot「视线判定」不受影响（双方都在凸圆内，连接线永不出圆）；玩家胶囊半径恒 8、停在 992，相机不再贴到 1000 的墙面上（原 bug 机制：径向钳制只约束**中心点**，相机因此落在墙面近裁剪面之内而「看出去」）。仿真侧 `r ≤ 1000` 的径向钳制**保留**——ADR-0004 的半径 1000 口径不变，钳制只是兜底。

后果：

- 目标距离在几何上不可达时，bot 退到「尽可能远」即停（CONTEXT「目标距离」的既有承诺至此兑现：不再死按 S、不再边界帧对打，改为沿墙内侧弧线侧移）。
- 墙开始吃子弹与曳光——贴边开火会看到弹着点在墙上，这是「掩体」语义的正常代价。
- 贴墙侧向被墙外推时靠 `on_blocked` / `wall_flip` 翻向（≤0.3s），不再靠「贴墙内拐」强行内拐。
- 「动态游走」档的行走廊硬约束（越界满幅归位）同样被这条衰减覆盖——两种「移动模式」共用同一注入点。
- 衰减幅度是手感量、一行可调；墙的验收走实机（`arena.gd` 不在 GUT 的纯逻辑缝上，ADR-0013），衰减侧进 GUT。

实现补充（2026-10-15，落地时实测修订）：

- 盒环的盒宽按**外缘半径**（`RADIUS + WALL_THICKNESS`）的切线跨度算：按内缘算时相邻盒只在内表面相接，外缘会漏出细缝。探针实测 192 条射线（96 段的中点与段缝交替取向）零漏缝，命中半径 1000.00–1000.54（0.54 是 96 边形相对圆的矢高，与视觉网格同量级）。
- 「贴墙守卫」门限再加 `WALL_GUARD_SLOP = 1.0` 容差：物理求解的余隙与几何离散让 bot 停在 `ARENA_RADIUS − 体型半径` 外侧零点几，不留容差则旧门限的问题换汤不换药（守卫永差一丝不生效）。
- `_pushes_outward` 加**相对容差**：真·切向时点积只剩 ±1e-13 浮点残差、符号随朝向角抖，原来的 `> 0.0` 会让守卫在正切位置随机生效。
- 解析边界对「已在圆上 / 圆外」返回 0（保守 = 「没有余量」），故前向探测在这个异常态退化为恒真——墙实体化 + 仿真钳制后 bot 不会跑到圆外，此分支只在钳制失效时可见。

_考虑过把围墙留作纯视觉、只把玩家径向钳制半径收到 `1000 − 8`——能解决相机穿墙，但子弹与曳光继续穿墙，不算「掩体」。考虑过给围墙开专用碰撞层、只挡玩家移动——爆炸半径最小，但与「遮挡物」语义分裂，且 bot 仍会挤到墙上。考虑过围墙碰撞用圆柱凹面网格（`ConcavePolygonShape3D` + `backface_collision`）——单个形状最省事，但零厚度、高速横移可隧穿、凹陷体去穿透不如凸体稳健，且段数与视觉不对齐。考虑过余量复用「前向探测」长度随布局变——把「以多快速度收力」和「多早翻向」两件不相干的事耦合。考虑过连「躲避」守卫一起删——接受墙边躲避白掷。_
