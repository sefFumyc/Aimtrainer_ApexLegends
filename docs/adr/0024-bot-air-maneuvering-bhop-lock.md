# bot 空中机动：跳跃锁存成 bhop，空中砍前后、变向分段

> 2026-10-11：本篇「空中变向分段」小节被 **ADR-0027** 取代（到点统一钉到升程一半执行）；「跳跃锁存成 bhop」与「滞空前后输入强制归零」两项决策继续有效。

票 11 落地后的实测修订（ADR-0023 的二轮）。用户把「跳跃间隔」双滑条都设 0.5 秒期待连跳（bhop），实际却是落地站稳约 0.28 秒才起跳——原因：滞空约 0.724 秒（286 初速 / 790 重力），间隔 0.5 < 滞空，到点必然在空中、按 0023 的「作废重抽」被丢弃，实际起跳节奏 2I = 1.0 秒，地面间隙 = 2I − 滞空，压间隔也压不掉。用户同时要求补上真人 bhop 的行为建模：空中不按 W、空中变向有真实的时间结构。

决策（六问定稿，全部硬编码、不进设置面板）：

- **空中到点改锁存**（修订 0023「作废不排队」——仅「空中」这一门控）：跳跃计时器到点时若在空中，照发 `jump` 信号——`MovementSimulator._pending_jump` 本就锁存到落地帧第一个物理子步立即起跳，落地零间隙。连跳节奏 = 滞空周期（0.724 秒/跳），间隔压进滞空以下得到的就是真 bhop。滑铲中到点、视线被挡到点**仍作废**（滑铲的跳跃归铲跳管；视线被挡跳是浪费频率配额——这两条门控与锁存无矛盾）。默认 4–12 秒档行为不变：到点在空中的概率仅 0.724/I，且就算撞上，锁存落地即跳也比作废更合理。
- **滞空前后输入强制归零**：凡 bot 在空中，喂给移动模型的 fwd 一律为 0，只保留左右「侧向」，落地恢复。空中无加减速，输入唯一效果是把速度向量朝 wish 方向旋转（≤6 rad/s）——前后输入会把速度拉向面朝方向（bot 永远面朝玩家 = 空中朝玩家窜），破坏侧移弧线；纯 A/D 才是 strafe。真人 bhop 空中不按 W，此即该行为的建模。起跳前已按住的 W 同样砍（全局规则，不区分「变向抽中」还是「起跳带入」）。
- **空中变向分段（只管自然变向）**：自然变向（变向计时到点：翻向 + 掷前后分量）到点时按垂直速度分档——
  - **上升期**（vz > 0）：挂起到**最高点**（垂直速度过零）才应用。剩余下降期（≤0.36 秒）内 6 rad/s 可转约 125°，多数变向能在落地前完成大半，落地不触发大角度「转向衰减」。
  - **下降期**（vz ≤ 0）：**丢弃**——不翻向、不掷前后分量，变向间隔照常重抽（与「作废重抽」同构）。若下降期照常变向，落地帧输入与速度夹角大，转向衰减 180° 档只保留 5% 速度 = 落地急刹。
  - **挂起中再到点**（快档变向间隔 0.2 秒可能）→ 作废：一次滞空最多挂起一个待执行变向，到最高点应用的是挂起时刻的方向。
  - 受击「躲避」与防撞翻向（前向探测 / 贴墙 / 物理受阻）**不受分段管制**，照常立即生效——反应与安全行为延迟即失效。
  - **贴墙内拐分支整体豁免**：bot 空中贴在边界上时，本帧输入整体替换为「朝圆心」向量（含前向分量）——安全纠正优先于空中管制，fwd 归零规则在此分支不生效（不豁免的话空中贴墙无法弧线回内，会沿切线滑出）。此为「fwd 一律为 0」的唯一例外，实现处注释已标明。
  - **勘误（ADR-0031，2026-10-15）**：「贴墙内拐」分支与 `_handle_walls` 已整体退役（围墙实体化，贴墙行为交给物理与仿真径向钳制），本条所称「『fwd 一律为 0』的唯一例外」随之不存在——空中 fwd 恒为 0，空中贴墙表现为沿墙切线滑行直到落地。
- **适用口径挂「空中」状态而非「bot 跳跃」开关**：铲跳（ADR-0016）的空中同样适用全部规则；「bot 跳跃」开关关闭只冻结跳跃计时器，不解除空中管制。

_考虑过下降期变向延迟到落地瞬间执行——被否决：观感是落地急转，且落地帧触发转向衰减急刹，恰是要避免的。考虑过挂起期间新到点覆盖旧挂起（到最高点应用最新状态）——用户选「后到作废」：一次滞空一次变向更接近真人对枪跳的手感，状态机也更简。考虑过把空中规则做成设置开关——被否决：行为建模不是训练参数，面板不膨胀。_
