# 文档优先，不写自动化测试，按垂直切片交付

Status: 部分被 ADR-0013 取代（「不写自动化测试」一条已作废；「文档优先」与「垂直切片」仍有效）

原版有大量单元测试（移动曲线、Bot 概率、躲避控制等）与 45KB 词汇表 + 35 篇 ADR。Godot 版只保留 **CONTEXT.md + docs/adr/** 这一半：领域词汇表与决策记录是跨实现可复用的资产，而测试框架（需引入 GUT 之类第三方插件，并把纯逻辑类与 GDScript 运行时绑定起来）由使用者自己的编程实现流程承担，不在本次交付范围内。ADR 从 0001 重新编号——原版 35 篇记录的是网页实现的历史，其中依赖浏览器、伴生进程、竞技场的部分已随概念一并作废。

交付按**垂直切片**推进：先跑通「圆形场地 + 玩家移动（移植速度曲线）+ 一把武器射击命中 + 一个靶 + 基础 HUD」，确认移动手感基线后，再依次铺 Bot AI → 训练器功能面（对局 / 计时器 / 预设 / 自动调径 / 设置面板）→ 角色动画与特效。

_理由：移动手感是整个项目的底座，也是最容易「在错误底座上堆一万行」的部分，必须先独立确认。_
