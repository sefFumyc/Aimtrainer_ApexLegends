# 演示模式：F2 会话级自动跟枪

起因：需要一个「给人看」的演示——按 F2 开启后由脚本代替玩家完成瞄准，展示「完美的瞄准动作」应该是什么样，并在屏幕左下角字幕提示已启用。拷问四轮定稿的取舍如下。

**接管范围**：只接管**视角**与**开火**两项。视角 = 相机 yaw/pitch 每帧由脚本写（玩家鼠标/右摇杆的视角输入被忽略）；由于**逻辑弹道只读 yaw/pitch**（既有机制），弹道自动跟随，无需改动开火链路以外的东西。开火 = 玩家的开火键输入被忽略，由脚本在「瞄到位」时击发。移动、跳跃、蹲/滑铲、开镜、切换武器**仍归玩家**——演示中仍可自己走位、自己开镜、自己换三把枪看不同手感。

**锁定口径**：锁定点是 bot **命中体当前立于地面之上那一段**的垂直中心（站立 ≈36u；躺姿压深 50u 后 ≈11u；铲跳随命中体整体跟抬），水平方向取命中体的中心轴——位于垂直轴上故不受朝向影响。之所以不写成固定的「bot 世界坐标 + 某高度」：bot 会滑铲（命中体整体压低 50u）与铲跳（命中体升空），固定高度会让准星锁在空气上、自动开火打空——与「完美瞄准」直接矛盾。跟随命中体即「所见即所中」，与曳光弹的命中点口径同源。

**追踪手感**：**限速平滑**，不是硬锁。硬锁（每帧精确贴合、无角速度上限）看不到任何「动作」，那是贴图不是技巧；取一个最大转向角速度 + 指数缓动，准星是「追」上去的，bot 变向瞬间有极短滞后然后追平——正是真人顶级跟枪的样子。视觉后坐力**保留**（真实感；它只踢渲染相机，逻辑朝向不受影响，准星仍锁在目标上）。

**开火**：视线方向与锁定点夹角 ≤ 阈值（约 2°）才开火——未到位不开火，不浪费子弹，准确率统计才配得上「完美」。武器用玩家当前所持（配合「切换武器」归玩家）。命中与射击照常计入「准确率」与击杀数——演示本就是这套枪法的展示。**判定取「到位电平」而非「到位上升沿」**：只要夹角在阈值内就持续按压——步枪连射，手枪 / 冲锋枪由 `Weapon` 的冷却与缓冲语义自动压到各自最高射速（手枪 3 发/秒、冲锋枪按组间节奏连组）。之所以否决票面建议的「每次到位只击发一发」：指数缓动到位后稳态残差 ≈1.4° 恒在 2° 阈值内，「到位」几乎只在初次捕获时产生一次上升沿，手枪会一次对局只响一发、演示反而变成「不开枪」。

**bot 侧一切照常**：照常躲避/滑铲/跳跃/开镜，照常受击反击，照常受伤、**可被击杀**、死亡 1.5s 后重生。重生后演示**重新走一遍定位**——限速平滑甩向新出生点（与跟枪同一套数学，观感是「击杀 → 空窗 → 干净利落地甩向新生点 → 继续跟枪」的完整循环）。bot 死亡的空窗期相机**冻结保持**不动：不转头看空气，重生一出现即从当前姿态开始重新定位。

**玩家侧只冻结「死亡」**：bot 照常开枪，玩家照常被扣血、受击红屏照常，但血量**封底 1**、永不触发「玩家重生」——演示的连续性优先；「照常开枪」的观感（枪声、曳光、红屏、血量下降）全部保留，只砍掉破坏连续性的「死亡 → 瞬移重生」。

**生命周期与字幕**：F2 **只在对局（PLAY）中可切换**（主菜单/结算/设置面板按下无反应），会话级、不持久化、不进「设置」面板（同「全屏热键」定位，ADR-0019）；离开对局（ESC 结算、回菜单）自动关闭。字幕 = 左下角一行小字（14px、透明度略低于主 HUD 数字），开关一开一关**立即显隐**、不做淡入淡出，走 `hud.gd` 的 `_draw()` 追加，不新增节点。

**参数全硬编码**（不进「设置」面板，与本作其它实测手感常量一致）：最大转向角速度（12 rad/s ≈ 688°/s）、指数缓动速率（40 /s——实测裁定：一阶滞后的稳态残差 = 目标角速度/缓动率，取 10 时残差 5.6°、只有 74% 的帧算「到位」、开火被反复中断；取 40 残差 ≈1.4°，准星横移中基本粘在身体上）、开火夹角阈值 ≤2°、收敛死区 0.05°、玩家血量封底 1；取值随实现落在 `DemoAim` 的常量里，锁定高度口径由命中体几何自动导出（无独立常量）。

**结构**：追踪数学（限速转向、到位判定）抽成**纯逻辑类** `DemoAim`，走 GUT 单测（ADR-0009 三层分离、ADR-0013 只在纯逻辑缝上测）；场景侧只做「喂目标点 / 读新朝向 / 读是否该开火」。

_考虑过把 bot 冻结不动——「演示瞄准动作」的靶不动就没有动作可看，演示价值低。考虑过硬锁（每帧贴合）——最省事，但没有任何「动作」可言。考虑过 bot 免疫伤害（演示连续）——用户选择保留「可击杀」的完整循环，代价是每 ~3.9s 有一次 1.5s 死亡空窗（默认步枪 25 伤害 / 10 发每秒 → 24 发即倒）。考虑过让玩家也免疫 bot 伤害——那「照常开枪」就名不副实，红屏与血量下降是演示中证明 bot 在还击的唯一证据。考虑过参数进设置面板——它是演示手感不是训练参数，进面板会污染「预设」的职责。考虑过锁定点固定用「bot 世界坐标 + 40u」——滑铲/铲跳期间必打空。考虑过把开火键仍留给玩家——脚本开火与玩家手按会叠加、打乱演示节奏。考虑过让演示射击不计入统计——演示正是这套枪法的展示，准确率该刷新。_
