# 砍掉空手状态、B 键长按双义与调试面板

原版的「空手」状态（收枪、速度修正器 1.0、禁开火禁开镜、Digit3 / B 长按切换）、B 键长按 ≥400ms 的收枪双义设计、以及 F1–F3 调试面板（速度曲线、瞄准开关、第三人称调试）在 Godot 版中全部移除。前两者是为键盘与手柄的按键稀缺所做的技巧性设计，而本项目不需要「空手跑图」这个战术档；后者是原版开发期的临时观察工具。相应词条已从 CONTEXT.md 删除。

**Consequences**: 「速度修正器」只剩持枪 0.87 与开镜 0.652 两档（原空手档 1.0 消失）。输入层不必实现「边沿 + 长按时长」的复合键语义，也不必维护「收枪即退镜」这类跨系统联动。武器切换收敛为：Q / 手柄 Y 就近切换，数字键 1、2 直接选择。
