# bot 空中变向钉到升程一半：起跳预读计时器取代上升/下降分档

票 12 落地后的实测修订（ADR-0024 三轮）。原「空中变向分段」把上升期到点挂起到**最高点**、下降期到点**丢弃**，用户提出：应用点提前到**升程一半**，且下降期到点不再浪费。障碍：变向计时器到点瞬间才结算（无提前时刻表），下降期到点发生时升程一半已经过去，「拉回」在实时结算下不可能——但**起跳沿预读计时器剩余值**即可预判本次滞空内是否会到点，从而把整次滞空的到点统一钉到升程一半执行。

决策（拷问三轮定稿，全部硬编码、不进设置面板）：

- **起跳沿预读**：变向计时器剩余 ≤ 滞空时长（0.724s，初速 286 / 重力 790）→ 本跳空中变向**预约成立**；剩余更大则空中无变向，到点落在地面照常立即应用。预读只看一眼，不预知后续重抽的到点——那些全部走作废通道。
- **钉点执行**：起跳后 0.181s（升程时间中点，此刻垂直速度由 286 降至 143）执行该次变向的内容——翻向、重掷前后分量、清「最短躲避时间」时钟；**变向计时器本身不动**，照旧走到原定时刻（必然仍在空中），到点后经现行「作废重抽」通道重抽——地面节奏与重抽时机零偏移（变向内容的掷骰时刻移到钉点，属有意变更）。
- **一次滞空一次**：钉点执行后本跳后续空中到点一律作废重抽（延续 0024「一次滞空一次变向更接近真人对枪跳」）。0.5s 快档下滞空 0.724s 内原定/重抽到点可多达 2~3 个，只有第一个（无论原定落在升程还是降程）在钉点生效。
- **豁免与口径不变**：受击「躲避」与防撞翻向（前向探测 / 贴墙 / 物理受阻）照常立即生效；贴墙内拐分支整体豁免（fwd 归零的唯一例外）；管制口径仍挂「空中」状态——铲跳（ADR-0016）空中同适用。起跳后、钉点前若发生躲避翻向，预约**不清除**——钉点照常执行（再翻一次），与 0024「躲避翻向当帧生效、预约照走」的叠加语义一致。
- **勘误（ADR-0031，2026-10-15）**：「贴墙内拐」分支与 `_handle_walls` 已整体退役（围墙实体化，贴墙行为交给物理与仿真径向钳制），本条所称「fwd 归零的唯一例外」随之不存在——空中 fwd 恒为 0；其余（躲避与防撞翻向立即生效、预约不清除）不变。

后果：

- ADR-0024 的「空中变向分段」小节整体退役（上升/下降分档、apex 沿清挂起、挂起唯一作边界巧合）——规则只剩「起跳预读 + 固定钉点 + 后续作废」三条。0024 的另外两项决策（跳跃锁存成 bhop、滞空前后输入强制归零）继续有效。
- **落地减速彻底消失**：钉点后剩 0.543s 空中旋转预算（6 rad/s ≈ 187° ≥ 180° 反向翻转所需），速度在落地前完全转正——0024 当初「下降丢弃」要避免的落地急刹在更早钉点下反而不存在，现行顶点规则残留的 ~125° 预算擦地减速（落地保留约 79% 速度）一并消除。

_考虑过下降到点挂到「降程一半」镜像执行——被否：用户意图是下降到点也提前到升程一半；且降程一半执行后只剩 62° 旋转预算，反向翻落地夹角 ~118°、保留约 46% 速度，重新引入要避免的落地减速。考虑过钉点之后空中再到点立即应用（滞空可连翻）——被否：用户选延续一次滞空一次变向的真人手感。_
