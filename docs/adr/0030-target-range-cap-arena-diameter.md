# 目标距离上限 = 场地直径（几何理论最大值）

「目标距离」的设置上限（滑条与 cfg 载入钳制）一直是随手定的 800，而场地是半径 1000 的圆——圆内两名实体能拉开的几何最大距离是直径 2000。决策（拷问一轮定稿）：上限改为 **2000 = 2 × `MovementSimulator.ARENA_RADIUS`**，抽共享常量 `GameSettings.TARGET_RANGE_MAX`（滑条与载入钳制引用同一来源）；bot 出生点越界改为沿场心方向缩回界内（`p *= limit / |p|`，与玩家出生路径 `_pick_player_spawn` 同款），兜底点同样缩回。走廊半宽 0–300、滑条步进 10、默认 400 与预设 27 项全部不动——纯上限扩展，不触发出厂默认二次烘焙，本机现值无感。

背景事实：出生余量界 = 1000 − 60（`SPAWN_BOUNDARY_MARGIN`）= 940，「目标距离」一旦超过它，玩家前方 ±90° 出生弧上的点**必然**全部越界；旧实现的 12 次重试全败后走兜底，兜底点不钳制、bot 落在场外一帧直到物理钳回（现存边界 bug）。CONTEXT「刷新」词条早已写明「半圆弧点越出对战域边界时沿其方向缩回场地内」，`_pick_spawn` 从未兑现——本次出生语义与词条对齐，bug 顺带修复；重试的避遮挡/避视锥检查照常在缩回后的点上进行。

_考虑过上限定 1000（假设玩家居场心）与 940（出生还能精确兑现距离的最大值）——被否：玩家会跑位，2000 才是真正可达的最大交战距离。考虑过出生只修兜底钳制、重试不动——被否：目标距离 = 2000 时 12 次重试必然全败，刷新位置退化到单一方向，随机性尽失。_

后果：

- 目标距离 > 940 时出生距离不可能精确兑现——bot 总在「尽可能远」处刷新（缩回后贴墙），属有意设计。
- 目标距离 = 2000 的实际可达距离取决于玩家位置：玩家居场心 ≈ 1000，玩家贴 bot 对侧墙 ≈ 2000；距离保持全程满幅后退直至贴墙，墙优先于距离（既有语义，无新分支）。
- 走廊远沿最大 2300 超出场界的部分被墙自然钳住，游走档「越界满幅归位」逻辑零改动。

勘误（ADR-0031，2026-10-15）：末条「距离保持全程满幅后退直至贴墙」被推翻——后退推力改为随「离墙余量」衰减、余量耗尽即零，bot 停在「尽可能远」处不再贴墙（「墙优先于距离」的语义不变，落地方式从「让位给贴墙内拐」换成「收力」）。
