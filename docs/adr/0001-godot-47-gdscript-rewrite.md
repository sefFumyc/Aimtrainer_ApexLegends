# 用 Godot 4.7.2 + 纯 GDScript 重写

原版是 TypeScript + Three.js 的网页应用，本仓库是它的引擎重写版。锁定 Godot 4.7.2-stable（查证时的最新稳定版，2026-08-18）与纯 GDScript，不引入 .NET。理由：需要移植的全部逻辑（移动积分、躲避控制、单发缓冲、计时器、对局统计）都是纯数学与状态机，没有一处依赖 .NET 独有的类型系统或运行时能力，纯 GDScript 免去 SDK 依赖与导出配置的复杂度。4.5/4.6 已进入停止维护状态，4.8 仅有 dev 快照（非稳定），故均不选；Godot 不存在 5.x。

_考虑过 Godot 4.x + C#：类型更强、类结构与原 TS 更接近，但为 100% 的纯逻辑移植收益支付整条 .NET 工具链成本不划算。_
