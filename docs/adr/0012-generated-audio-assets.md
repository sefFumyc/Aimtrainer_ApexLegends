# 音效改为构建期生成的资产文件，不做运行时合成

原版的枪声、击中、击杀、预哔、开始哔是运行时用 WebAudio 合成的定频短爆点：155Hz（枪声）/ 200Hz（击中，爆头 +2 半音）/ 660Hz（预哔）/ 990Hz（开始哔），约 30ms 时长、4ms 缓起音、陡衰减、无噪声瞬态，枪声每发 ±5% 音高微差。Godot 没有等价的「运行时合成一段带包络的正弦爆点」的现成节点，`AudioStreamGenerator` 需要自己喂缓冲区，复杂度与该反馈的价值不成比例。

改为在构建期用脚本按同一套包络与频率参数生成这几个短音，作为资产文件入库，运行时用普通音频播放器播放；±5% 音高微差用播放器的音高缩放实现，不需要预生成变体。

_考虑过运行时用 `AudioStreamGenerator` 合成（保持与原版一致的「零音频资产」特性），但需要自己管理缓冲与采样时钟，收益只有「仓库里少四个小文件」。_
