# Bot 用前向探测变向避障，不引入导航寻路

原版 Bot 没有寻路：它在一条走廊里做直线侧移，只对圆形外墙做径向反向。场地引入遮挡物后，Bot 会直接撞上柱子卡住。本项目选择保留「无寻路 + 直线侧移」的模型，只增加一条**前向探测**：探到遮挡物或边界时提前触发变向，并复用「撞墙反向」的优惠语义（只翻方向、不重掷前后分量、不重置变向/切换计时，但重置「最短躲避时间」时钟）。这样躲避控制（三档模式、模式权重、走廊、前后分量、贴墙内拐）的全部语义零改动，Bot 仍是「照搬」而非「重写」。

_否决接入 `NavigationAgent3D` + 烘焙导航网格：它会推翻躲避控制的语义——三档横移节奏与走廊都是为「无寻路的直线侧移」设计的，寻路会引入路径跟随这个正交的运动源；成本也显著更高。_

_勘误（ADR-0031，2026-10-15）：上面「躲避控制……的全部语义零改动」的名单里含「贴墙内拐」——该机制已随围墙实体化整体退役，本条其余（前向探测复用撞墙反向语义、三档模式 / 走廊 / 前后分量不动）不变；边界轴改由「后退推力随离墙余量衰减」承担。_
