# 04 — 切片四：角色动画与特效

Status: ready-for-agent

对应 spec: `../spec.md`（切片四）。术语以 `CONTEXT.md` 为准。依赖票 01、02。

## 目标

让靶子的移动「看起来是人在走」，让开火「看起来有枪口和弹道」。这一票**不动任何数值与判定**，只补表现层。

## 范围

### 1. 角色动画（靶子）

- 姿势混合：站立 / 蹲伏 / 滑铲等姿势之间的混合，切换时机与移动状态机对齐（状态是切片一和二已经算好的，本票只负责播）。
- 步态周期：按实际水平速度驱动步频，而不是按固定时间循环。
- 朝向侧偏：躯干在移动方向与瞄准方向之间做侧偏，而不是整体瞬转。
- 用 KayKit Adventurers（CC0）的骨骼与动作；用 `AnimationTree` / `AnimationPlayer` 组织。

### 2. 特效

- 枪口火光：开火瞬间在枪口位置播放，可单独开关。
- 曳光弹：从枪口到命中点的弹道表现，可单独开关。
- 脚底接触暗影：靶子脚下跟随的接触阴影。

## 验收条件

1. 靶子加速、减速、换向时步频随之变化，没有「原地滑步」。
2. 靶子从站立切到蹲伏、切到滑铲时姿势平滑过渡，不出现瞬间弹跳。
3. 靶子侧向移动且同时瞄准玩家时，躯干有明显的朝向侧偏。
4. 开火能看到枪口火光；关闭该设置项后不再出现。
5. 开火能看到曳光弹，且落点与命中点一致；关闭该设置项后不再出现。
6. 靶子脚下有跟随的接触暗影，不穿地不漂移。
7. 以上全部开关**不改变任何伤害、命中判定与移动数值**（对同一段输入回放，结果与未开特效时逐帧一致）。
