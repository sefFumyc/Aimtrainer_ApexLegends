# 01 — 切片一：圆形场地 + 玩家移动 + 两把枪 + 靶 + 基础 HUD

Status: ready-for-agent

对应 spec: `../spec.md`（切片一）。术语以 `CONTEXT.md` 为准，决策以 `docs/adr/0001-0012` 为准。

## 目标

在 Godot 4.7.2-stable 上跑通最小可玩闭环：**圆形场地（含可切换遮挡物）+ 玩家移动（完整速度曲线 / 滑铲 / 蹲伏 / 跳跃 / ADS）+ 步枪与手枪 + 靶（命中判定与爆头）+ 基础 HUD**。

这一段的目的不是功能齐全，而是**确认移动手感基线**。靶子只作为可命中的受击体存在，AI 与动画都不在本票范围内——手感出错时才不至于无法区分是移动还是 AI 造成的。

## 范围

### 1. 工程脚手架

- Godot **4.7.2-stable** 项目（Forward+ 渲染器，Windows 桌面）。纯 GDScript，不引入 .NET。
- 三层结构落地：实体与组件用 `.tscn` 场景；可移植纯逻辑写成**不依赖节点树**的逻辑类，由场景调用；全局设置用 Autoload 单例承载，持久化到 `user://` 配置文件。（ADR-0009）
- `.gitignore` 已存在，确认其覆盖 `.godot/` 与 `*.translation`。
- **补上票务约定文件**：`AGENTS.md` 与 `docs/agents/`（`issue-tracker.md` 记 tracker 约定、`triage-labels.md` 记 triage 标签词汇）。本 spec 与这四张票是按这套约定建的——一功能一目录 `.scratch/<feature-slug>/`、spec 为 `spec.md`、实现票为 `issues/NN-<slug>.md` 且从 01 编号、`Status:` 行近顶部、评论追加到底部 `## Comments`——但目前这套约定只存在于参考仓库 `D:\Tools\test\aimtrainer`，本仓库没有留痕。补上后，后续迭代不必再回参考仓库取约定。

### 2. GUT 接入与首个测试

- 引入 GUT，让测试可命令行无头运行。
- 写**移动积分**的行为测试（本票唯一必须有的测试，是本项目的核心资产回归网）。断言清单见 spec 的 `## Testing Decisions` 第 1 项：速度向量轨迹、90° 换向保留率、松手减速到 0 的时长、滑铲初速倍率、滑铲跳跃倍率、空中速度上限 500 u/s、ADS 封顶 130.1 u/s、多轴合并钳制。
- 只断言外部行为，不断言内部状态字段与私有方法。

### 3. 圆形场地与遮挡物

- 边界为圆心在原点、**半径 1000 的圆**，径向判定（靶子的「撞墙反向」依赖它）。（ADR-0004）
- 视觉为程序化地面 + 环形围墙，不搬原版竞技场看台。
- 遮挡物为程序化**箱体与柱体**，**参与碰撞且参与射线**。
- 「场地布局」设置项三档：空旷 / 少量遮挡 / 多遮挡，默认少量遮挡。
- 生成时避开玩家出生点与靶子刷新点。

### 4. 玩家移动

- `CharacterBody3D` 只用来做碰撞求解（`move_and_slide()`），**`velocity` 全部由脚本自己算**，按固定子步做分段线性积分，与参考实现同构；不使用 Godot 默认加速与摩擦。（ADR-0002）
- 移植：速度保留率 `cos(θ/2)^1.2`、转向衰减、速度修正器（持枪 0.87 / 开镜 0.652）、疾跑 299 u/s（仅前进半球）、蹲伏行走 92 u/s、滑铲（初速 ×1.53、≈210 u/s² 减速）、滑铲跳跃倍率（`2.454 − 速度/299 × 0.919`）、跳跃（垂直初速 286 / 重力 790 / 最大高度 ≈55.5）、空气控制（≤6 rad/s、速度大小不变）。
- ADS 时移速封顶降到 130.1 u/s。

### 5. 相机与 viewmodel

- 主相机 FOV 92.35°，开镜 76.64°；开镜 0.22s / 退镜 0.088s。
- 开镜灵敏度倍率可单独设定，不改动开镜移速。
- 武器模型用 `SubViewportContainer` + `SubViewport`（透明背景）+ 独立武器相机 + `RemoteTransform3D` 跟随主相机，cull mask 做几何隔离。（ADR-0008）

### 6. 武器与命中

- 步枪：连射 10 发/秒，身体 25 / 爆头 35。
- 手枪：单发，最快 3 发/秒，身体 70 / 爆头 110；冷却期内的点击**缓冲一发**，切枪重置缓冲。
- 头部命中 ×2 伤害。
- 弹道被遮挡物阻挡。
- 键位：1 / 2 选枪、Q（手柄 Y）就近切枪、左键开火、右键开镜。**不含**空手与 B 键长按双义。（ADR-0010）

### 7. 靶（无 AI）

- 靶子作为可命中的受击体：有血量（600）、能被击杀、死亡 1.5s 后刷新、体型半径可调（4–60，默认 8）。
- 切片一可以让它静止或做最简恒定侧移即可；**躲避控制、前向探测、视线判定、概率开火全部不做**（切片二）。
- 命中判定使用与玩家同构的体型定义（总高 72：身体圆柱高 60 直径 16 + 头球半径 6）。

### 8. 基础 HUD

- 屏幕中心固定实心圆点准星。
- 命中：白色 X 保持 250ms + 60ms 淡出；击杀：更大红色 X 保持 480ms + 80ms 淡出，且不被后续命中打断。
- 实时显示命中/总射与准确率、玩家血量与靶子血量、击杀数与计时。

### 9. 音频

- 按参考实现的包络与频率**在构建期生成短音资产入库**：枪声 155Hz、击中 200Hz（爆头 +2 半音）、约 30ms、4ms 缓起音、陡衰减、无噪声瞬态。（ADR-0012）
- ±5% 音高微差用播放器的音高缩放实现，不预生成变体。不使用 `AudioStreamGenerator` 运行时合成。

### 10. 美术资源

- 枪械用 **Kenney Blaster Kit**（CC0），角色用 **KayKit Adventurers**（CC0）。（ADR-0007）
- **只提交项目实际用到的文件**（筛掉资源包里附带的其他格式版本），其余不进仓库；**不使用 Git LFS**。理由与不可逆的代价见 ADR-0007 的 Consequences——注意这是单向承诺，提交错了删不掉。
- 每个第三方资源包入库时附**许可说明文件**，标明来源与边界。

### 11. 引擎安装与启动校验

- 下载并安装 Godot **4.7.2-stable**（该路径在本仓库之外，可能突破沙箱写盘限制）。
- 做一次启动校验：无头导入资源、跑通 GUT 测试、打开主场景无报错。

## 验收条件

1. 命令行无头运行测试套件通过，其中移动积分的断言全部为绿。
2. 启动游戏后：可用 WASD 移动、Space 跳跃、Shift 疾跑、Ctrl/C 蹲伏、疾跑中蹲触发滑铲、滑铲中跳得到加成；转向时有可感知的减速收敛，而不是镜头吸附。
3. 按住右键完成开镜，FOV 与移速同时按上述数值变化，贴柱子时枪不插进柱子。
4. 1/2 切枪生效；步枪连射、手枪单发且冷却期点击被缓冲一发。
5. 射击靶子能命中并计数；爆头伤害 ×2；躲在遮挡物后面的靶子打不到。
6. 靶子血量归零后 1.5s 重新出现。
7. 设置里切换「场地布局」三档后，遮挡物数量随之变化，且不生成在出生点与刷新点上。
8. 开关枪口火光 / 曳光弹设置项有效。
9. HUD 显示准星、命中/击杀提示、准确率、双方血量、击杀数与计时，且数字与实际对局一致。
10. 关闭游戏再启动，设置项保持上次的值。
