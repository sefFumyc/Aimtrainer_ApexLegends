# 05 — 试玩反馈批量修复

Status: done

对应 ADR-0015（侧偏收敛）。术语以 `CONTEXT.md` 为准。依赖票 01–04（全部已 done）。

## 目标

玩家试玩后提出 7 项反馈：全部是**表现层与输入层**修复，不动伤害、命中判定与移动数值。

## 清单与验收

### 1. bot 侧偏收敛（45°/15° → 25°/8°）

`src/scenes/pose_lean.gd` 三个角度改 25 / 8（头保持 −肩偏 = 0）。CONTEXT 与 ADR-0015 已先行改好。
- 验收：横移时腿不再「起跑预备」感；上身仍朝瞄准方向；满速本地骨姿 +25 / −17 / −8（世界净偏角：骨盆 25、肩 8、头 0）。
- **定稿流程**：改完截图给用户过目，用户点头才算验收（ADR-0015 里承诺的微调窗口）。

### 2. 设置滑条：数显 + 可输入 + 灵敏度量纲统一

所有 HSlider 旁边加数值 Label + LineEdit（可直接键入，失焦/回车生效），显示与输入**保留两位小数**。
借道修正：鼠标灵敏度从 rad/px（0.0022 量纲）改为**倍率**（默认 1.0，区间参照手柄 0.2–5.0）——CONTEXT「灵敏度」本来就写的是乘数，现状是实现违背词汇表。旧配置迁移守卫：区间外的历史值丢弃回落默认（同手柄上次的做法）。
- 验收：每根滑条拖动时数值实时刷新；键入越界值被钳制；旧 `settings.cfg` 里的鼠标灵敏度 0.0022 读入后自动回落为 1.0。

### 3. 游戏入口

- 先落 `启动游戏.bat`（调本机 Godot 控制台 exe 跑主场景，双击即玩）。
- 再配 `export_presets.cfg`（Windows Desktop），引导安装 4.7.2 导出模板（当前 `export_templates` 为空，需下载），模板装好后导出真 exe。
- 验收：不打开 Godot 编辑器/引擎控制台也能从桌面双击进入游戏；exe 路径不依赖仓库。

### 4. 曳光弹与枪口火光不投影

`main.gd` 的 `_make_fx`（玩家与 bot 两组）：火光 MeshInstance3D 与曳光 MeshInstance3D `cast_shadow = OFF`（现状默认 ON，实拍确认在地面投影）。
- 验收：开火瞬间地面只有靶/人的影子，无短促光斑影；开关火光/曳光设置不回归。

### 5. bot 拿枪（替换刀盾）

Knight.glb 内置剑/盾网格隐藏（`visible = false`），**对应命中盒一并移除**（部件名含 sword/shield，实现时以实际部件名为准）；kenney `blaster-e` 步枪挂到右手骨（`BoneAttachment3D`），朝向对准射击方向。
- 验收：bot 手持步枪随跑动摆动；对剑盾原位置开枪不再命中；爆头判定不受影响；伤害与射速数值零改动。

### 6. 设置面板深色高对比主题

面板背景改深色（不透明度 ~90%）、文字纯白、控件描边加深；开关激活态用高亮色（青/绿系）、禁用态变灰。所有分页统一。
- 验收：沙地亮背景下每一项的激活/禁用一眼可辨；滑条轨道与已填充段对比明显。

### 7. POV 枪四连修

- **拿反**：`viewmodel.gd` 的 `_fit_model` 朝向修正，枪口指向屏幕前方（截图确认）。
- **不投影**：viewmodel 枪模 `cast_shadow = OFF`（FPS 惯例，用户已确认不加）。
- **拉近**：rig 位置调近（右下角贴边、枪身更贴近相机）。
- **纯视觉后坐力**：开火瞬间枪体后坐+上抬、弹性回位；相机轻踢上抬后回中（COD/Apex 手感）。**关键约束**：逻辑瞄准（yaw/pitch 与开火射线）与渲染相机分离，后坐力只动渲染——弹道与命中零影响（「不要产生实际的后座，动起来就好」）。
- 验收：开枪有可感抖动与回位；对静止靶连射，弹着点分布与不开后坐力时逐帧一致。

## 备注

- 全票为表现/输入层：`PoseLean` 角度、FX 阴影、viewmodel、主题、入口都不参与游戏性计算；唯一动逻辑缝的是滑条量纲（`GameSettings` 字段语义修正 + 迁移）。
- 票 04 已把动画改 `LOOP_LINEAR`、步态等比例，本票不回归那些点。
- 临时探针脚本用完即删（tools/ 下不留痕迹）。

### 收尾记录（2026-10-02，定稿 + 根修 + 导出）

1. **侧偏定稿（四轮截图评审，票面承诺的微调窗口）**：25/8 → 18/8（嫌多）→ **30/10（定稿）**。实现基座随评审重做：探针实测横移动画自带的骨盆世界角一个步态周期在 −32°~+53° 间摆，票 04 的静态增量+反旋抵不掉，改为**逐帧按「动画当前姿态 → 期望世界净偏角」强制**——满侧偏世界净偏角恒为骨盆 30 / 肩 10 / 头 0（探针 `hips=30.0 / chest=10.0 / head=0.0`）。`pose_lean.gd`、CONTEXT「朝向侧偏」、ADR-0015 三处同步定稿值。
2. **挂枪根修（弃用 `BoneAttachment3D`）**：Knight.glb 的 `handslot.r` 骨链带非均匀缩放（全局 scale ≈ (29.1, 25.5, 25.6)），`BoneAttachment3D` 把剪切传给子节点，枪被毁形成看不见的碎片（前几轮截图里 bot 步枪「消失」的根因）。改为枪挂 Target 根下，每帧手动写全局变换 = 骨全局位置 + 骨旋转纯四元数（丢弃缩放）× `WEAPON_ROT`，缩放用世界级标量（最长边归一到 `WEAPON_LENGTH=30`，实测 21.58 三轴等比）。截图验收：斜侧金枪完整、正面枪从右肩后露出。
3. **导出**：4.7.2 导出模板装好后 `--export-release "Windows Desktop"` 出 `build/aim-trainer.exe`（104.1 MB，`build/` 目录需先建）；启动验证 RUNNING 正常。验收 3 达成：双击 exe 即玩，不依赖仓库路径。
4. **清理**：tools/ 临时脚本（capture.gd、probe_model.gd、inspect_rig.gd 残留 uid）已删，仅保留 gen_audio.gd。
