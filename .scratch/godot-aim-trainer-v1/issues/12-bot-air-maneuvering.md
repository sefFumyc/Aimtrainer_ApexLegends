# 12 — bot 空中机动：跳跃锁存成 bhop，空中砍前后、变向分段

Status: done

术语以 `CONTEXT.md` 为准（「空中机动」为本票新增，已落稿；「bot 跳跃」词条已修订）。决策全录见 ADR-0024（ADR-0023 已加修订注记）。依赖票 11（已 done）。

## 目标

票 11 实测二轮：①「跳跃间隔」双滑条设 0.5/0.5 期待连跳（bhop），实际落地站稳约 0.28s 才跳——「作废重抽」语义下地面间隙 = 2I − 滞空 恒不为零；②补上真人 bhop 行为建模：空中不按 W、空中变向有真实时间结构（上升期改向、下降期不改）。

## grilling 定稿（2026-10-09，六问）

1. **空中到点改锁存**（修订 ADR-0023「作废不排队」仅空中门控）：跳跃计时器到点在空中照发 `jump`，`MovementSimulator._pending_jump` 锁存到落地帧立即起跳——连跳节奏 = 滞空周期 0.724s，真 bhop；滑铲中/视线被挡到点**仍作废**；
2. **滞空前后输入强制归零**：凡 bot 在空中 fwd 喂 0（含起跳带入的 W），落地恢复——真人 bhop 空中不按 W（W 把空中速度拉向面朝方向，破坏 strafe 弧线）；
3. **空中自然变向分段**（只管自然变向）：上升期（vz>0）到点挂起到**最高点**（垂直速度过零）应用；下降期（vz≤0）到点**丢弃**（不翻向、不掷前后分量，间隔照常重抽）；受击「躲避」与防撞翻向**不受管制**、立即生效；
4. **挂起唯一**：一次滞空最多挂起一个待执行变向，挂起中再到点作废（Q5 用户选 B）；
5. **全部硬编码**不进设置面板；规则挂 `airborne` 状态而非「bot 跳跃」开关（铲跳空中同适用）。

## 清单与验收

### 1. AvoidanceController 变向门（ADR-0024）

`avoidance.gd` `update` 增加可选参数 `allow_flip := true` 并返回本帧是否真的自然变向：`false` 时到点作废——不翻向、不掷前后分量、间隔照常重抽、`since_flip` 不清。
- 验收：默认参数行为与现状逐字节一致；作废时 flip_timer 重抽、dir/fore_mix 不动。

### 2. BotAi 空中机动（ADR-0024）

`bot_ai.gd`：`_tick_jump` 去掉 `airborne` 门控（锁存）；空中输入管制——起跳沿记快照侧向、上升期喂快照、apex 应用挂起（快照跟进）、下降期喂 `avoidance.dir`、fwd 全程归零；`avoidance.update` 传入 `allow = not (armed or 下降)`；防撞翻向三处调用点与受击躲避统一走快照同步（立即生效）。
- 验收：0.5/0.5 间隔出现连续 bhop（空中区间 ≥ 两跳连贯）；空中速度不被拉向玩家；变向分段四边界（上升挂起 / 下降丢弃 / 挂起中后到作废 / 防撞躲避立即）行为正确；多跳连跳时快照与挂起状态正确接力。

### 3. 测试

`test_bot_ai.gd` 新增空中机动用例；票 11 的 `test_no_rejump_mid_air` 语义更新（锁存后 0.05 间隔 = 预期全程连续空中，改写为连跳守恒断言）。
- 验收：GUT 全量回归全绿。

### 4. 收尾

导出 `build/aim-trainer.exe`；code-review；提交 master。设置/预设/面板/场景装配**零改动**（全硬编码纯逻辑层）。

## Comments / 2026-10-09 — 实现收尾（agent）

**变向门**（`avoidance.gd`）：`update(dt, allow_flip := true) -> bool`，返回本帧是否真的自然变向。作废通道 = 不翻向、不掷前后分量、`since_flip` 不清、flip_timer 照常重抽。到点分支顺序刻意保持旧 RNG 序（翻向 → 掷 fore_mix → 重抽 flip_timer）——code-review 发现初版把重抽提到 allow 判定之前会错位同种子序列，已修回。

**空中机动**（`bot_ai.gd`）：三态成员 `_air_strafe`（侧向快照）/ `_air_armed`（挂起唯一）/ `_air_prev`（沿检测）；`update` 开头沿检测先于变向判定（起跳沿锁快照、落地沿清挂起、**apex 沿消费挂起并快照跟进**——锁存 bhop 帧级 airborne 连成一段无落地沿，挂起清零只能挂 apex 沿）；`allow = not (air and (armed or 下降))`；输入组装常规路径空中覆盖（fwd=0、strafe 分快照/dir），贴墙内拐分支整体豁免（安全行为，已记入 ADR-0024）；防撞翻向三处（前向探测 / 贴墙外推 / on_blocked）统一走 `_wall_flip()`（翻向 + 快照同步），`_try_dodge` 命中后同步快照——不守恒测试（上升期翻向当帧生效）现实现即绿；`_tick_jump` 仅删 `sim.airborne()` 门控，滑铲 / 视线门控保留；`spawn()` 与 `take_damage` 致死分支清三态。全部硬编码，设置 / 预设 / 面板 / 场景装配零改动。

**测试**（TDD 红→绿）：`test_bot_ai.gd` 改写 `test_no_rejump_mid_air` → `test_fast_interval_chains_continuous_air`（0.05 间隔 2s 落地数 = 0）；新增 6 条——0.5/0.5 连跳（连续空中区间 >1.4s）、空中砍前后（起跳 |vz|>60 → 0.35s 后 <20）、上升挂起（t≈0.35 到点：dir 已翻、vx_mid 维持起跳方向、vx_late 反向）、下降丢弃（t≈0.80 到点：dir 不翻、间隔照常重抽）、挂起中后到作废、防撞 / 躲避空中立即生效（守恒 ×2）。新 helper `follow_player`（玩家每帧跟随 bot 正前方 120）锁定面朝 yaw 使侧向轴恒 ±x，速度断言才可用纯分量口径。**坑**：`flip_timer` 自 spawn 起倒数，初版两条用例把它当「相对起跳时刻」设值，实际到点落在地面期 / 上升期走了错误路径（其一还是假绿），已按时序前提修正（0.35 = 上升期、0.8 = 下降期）；重抽断言从硬编码 0.3 改为对照当前模式区间下限。

**验收**：GUT 全量回归 183 tests / 1270 asserts 全绿（本票 +7 用例改写 1）。导出 `build/aim-trainer.exe`。code-review 双轴：Standards 零硬违规（三态复位重复 / 快照同步四处 / 快照存 float 三条判断性发现，与既有复位风格一致或收益微小，未采纳提取）；Spec 收口两处已落实（RNG 序修正、贴墙内拐豁免记入 ADR-0024）+ EOF 换行修补；多跳连跳的快照接力维持隐式不变量（`_wall_flip` 聚拢同步点 + 代码注释），未加专用测试。
