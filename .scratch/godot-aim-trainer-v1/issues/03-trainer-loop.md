# 03 — 切片三：训练器功能面

Status: ready-for-agent

对应 spec: `../spec.md`（切片三）。术语以 `CONTEXT.md` 为准。依赖票 01、02。

## 目标

把「一个能打的场地」变成**能用来练习的训练器**：会分段、会计分、会存配置、难度会跟着水平走。

## 范围

### 1. 对局与结算

- 双方血量各 600；玩家归零后**满血复活**而不是结束对局；复活点落在靶子的视线锥之外且不在遮挡物里。
- 击杀靶子**立即回满血**。
- 可选**吸血**：按本次伤害回血、封顶 600。
- 按 ESC 结束当前对局并给出结算快照（准确率、击杀、死亡、用时）。
- 实时统计与结算快照的**准确率口径必须一致**；击杀回血不溢出。

### 2. 间隔计时器

- 可开关。阶段机：**准备段 → 游玩段 → 休息段 → … → 最终结算**，无尾休息。
- 准备段：5 秒大字倒计时 + 逐秒预哔（660Hz）。
- 开始哔 990Hz。
- 休息段显示剩余秒数与本轮战绩。
- **休息段不可跳过**，只有 ESC 能退出整个会话。

### 3. 自动调径

- 可开关：按每段准确率自动调小 / 调大靶子体型半径。
- 每段显示「半径 旧→新」的记录。

### 4. 设置面板与预设

- 分页面组织（「目标与 bot」「躲避与移动」等），不是一长条。
- 鼠标与手柄灵敏度可分别设定。
- 19 项训练参数可存为**命名预设**。
- 选中预设后，一切改动**自动写回该预设**，不需要额外点保存。
- 「不选预设」这个状态就是全局设置本身，行为与没有预设时完全一致。
- 设置改动**立即生效并持久化**，重启不丢。
- 画面质量低 / 中两档，映射到后处理开关与阴影精度（低档默认关闭 SDFGI/SSIL/体积雾等性能大户）。

## 验收条件

1. ESC 结束对局后看到的准确率 / 击杀 / 死亡 / 用时，与过程中 HUD 实时显示的一致。
2. 玩家血量归零后满血复活，对局不结束；复活点不在遮挡物里、不在靶子视线锥内。
3. 击杀靶子立刻回满血；开启吸血后按伤害回血且不超过 600。
4. 开启计时器后完整跑完「准备→游玩→休息」循环，最后一段游玩结束直接结算，**不留一个尾休息段**。
5. 准备段有 5 秒倒计时与逐秒预哔；开始时有 990Hz 哔声；休息段显示剩余秒数与本轮战绩且无跳过入口。
6. 开启自动调径后，每段按准确率调整靶子半径，并显示「旧→新」。
7. 存一个预设、改几项参数、切到另一个预设再切回来，改动仍在。
8. 「不选预设」时改参数的行为与预设机制不存在时一致。
9. 关闭游戏再启动，全局设置与预设都还在。
10. 画面质量切到低档后帧率明显上升，切回中档恢复。
11. **计时器阶段机**与**对局统计**各有行为测试通过（断言清单见 spec 的 `## Testing Decisions` 第 4、5 项）。

- 参考实现里的设置持久化按「**网址源**」隔离，这个语义随网页载体一起消失，不要带过来。
- 预设的「自动写回」是刻意设计（避免多一次保存动作），不要改成显式保存按钮。
