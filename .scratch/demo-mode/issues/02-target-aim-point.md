# 02 — 靶的瞄准点接口

Status: ready-for-agent

## 目标

给 `Target` 增加一个「当前可瞄准点」读数，供演示模式每帧取用；口径必须是**命中体局部空间的躯干中心**换算到世界（ADR-0033），否则滑铲/铲跳期间会打空。

## 接口（建议）

- `Target.aim_point_world() -> Vector3`：返回命中体局部 `(0, TORSO_CENTER_Y, 0)` 的世界坐标；`TORSO_CENTER_Y` 取约 40（角色总高 72、脚在原点，位于垂直轴上故与朝向无关）。
- 另需一个「当前是否可作为锁定目标」的读数（可用既有的存活 / 可见状态，如 `Target.visible` 或 `ai.alive`），供演示模式判断空窗。

## 验收

- bot 站立时该点落在躯干中段（世界高度约等于命中体原点 + 40）。
- bot 滑铲（命中体压低 50）与铲跳（命中体升空）时该点随命中体一同位移，仍落在身体上。
- 不新增绘制、不改变既有碰撞与命中判定。

## 验证

GUT 侧若有纯逻辑缝可断言；否则实机探针（命中体未挂场景时不进 GUT）。
