# 03 — F2 输入、开关生命周期、左下角字幕

Status: ready-for-agent

## 目标

打通「按 F2 开关」这一层：输入动作、会话级开关、状态字幕，且**不碰**视角接管（那是 04）。

## 内容

- `project.godot` 的 `[input]` 段新增动作（建议 `toggle_demo`），F2 的 `physical_keycode`。注意该文件注释语法是 `;` 不是 `#`，且**导出会重写该文件**，改动前后照既有习惯处理。
- `main.gd`：一个会话级 bool（命名建议 `_demo_mode`）、在既有热键处理处（同 `_toggle_fullscreen` 的位置与风格）响应 F2；**仅 PLAY 阶段**响应；进入结算 / 回主菜单时强制关闭。
- `hud.gd`：新增一个设置入口（如 `set_demo_active(on: bool)`），在 `_draw()` 里于**左下角**追加一行 14px 小字「演示模式已启用」、透明度略低于主 HUD 数字；不做淡入淡出；不新增节点。
- 字幕位置在**左下角**，注意既有 HUD 数字在左上角，别写反。

## 验收

- 对局中 F2 → 字幕出现 / 消失；主菜单、结算、设置面板中 F2 无反应。
- 设置面板采集键位期间（若既有热键短路机制生效）F2 不触发。
- 进入结算或回主菜单后字幕必定消失。

## 验证

实机 + 既有热键的同类路径回归（F11 仍正常）。
