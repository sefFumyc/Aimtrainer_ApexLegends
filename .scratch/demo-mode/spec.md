# 演示模式（F2 自动跟枪演示）

## 用户故事

作为演示者，我想要按 F2 让游戏自动演示「完美瞄准动作」是什么样：相机平滑跟住 bot 的身体、瞄到位就开火，屏幕左下角有状态提示；再按一次 F2 回到手动瞄准。

## 决策来源

全部设计取舍见 [ADR-0033](../../docs/adr/0033-demo-mode-locked-aim.md) 与 [ADR-0034](../../docs/adr/0034-demo-mode-visibility-and-aim-momentum.md)，术语见 `CONTEXT.md`「演示模式」与「可见性」。本 spec 只做范围与验收，不重复论证。

## 范围

**做**：F2 会话级热键（仅对局中可切）；左下角字幕；脚本接管视角与开火（限速平滑跟枪、夹角阈值内击发）；锁定点为 bot 命中体局部空间的躯干中心（随躺姿/铲跳跟随）；bot 死亡空窗期相机冻结保持、重生后平滑重新定位；玩家血量封底 1 不触发重生；**「可见性」门控**（被「遮挡物」/「围墙」挡住时不锁定、不按住开火，拉枪带惯性滑行收住，重新可见立即恢复）；参数硬编码；追踪数学抽纯逻辑类并加 GUT 用例。

**不做**：不进设置面板、不持久化、不给手柄绑键、不加淡入淡出、不做硬锁模式、不改动 `MovementSimulator` 与 bot 的 `BotAi` 行为、不新增 HUD 节点；**不按 FOV / 画面外判不可见**（相机本就一直在追 bot）；**不做部分可见**（单根射线打瞄准点，命中即可见）；**死亡空窗不加惯性**（用户裁定：人类高手会预判死亡直接停住，不滑行）。

## 验收标准

1. 对局中按 F2：左下角出现「演示模式已启用」，相机开始平滑追踪 bot 躯干、瞄到位时自动开火；再按 F2 字幕立即消失、立即回到手动瞄准。
2. 主菜单 / 结算 / 设置面板中按 F2 无任何反应。
3. 演示中鼠标与右摇杆无法改变视角；WASD 移动、跳跃、蹲/滑铲、右键开镜、1/2/3/Q 换枪仍然有效。
4. 演示中玩家左键不生效（开火由脚本接管）。
5. bot 滑铲（命中体压低）与铲跳（命中体升空）期间准星仍落在身体上、自动开火仍命中。
6. bot 被击杀后 1.5s 空窗期相机保持不动，重生后以限速平滑方式甩向新位置。
7. 演示中玩家血量被打到 1 时不再下降、不触发「玩家重生」；受击红屏照常。
8. 演示中射击照常计入准确率、击杀照常计数、击杀音/红 X 照常。
9. ESC 结算或回主菜单后演示模式自动关闭。
10. GUT 全绿，且脚本数 / 用例数与新增用例数一致（防 Parse Error 静默漏测）。
11. bot 被「遮挡物」/「围墙」挡住**超过宽限期（约 0.1s）后**：脚本不锁定、不按住开火——一颗子弹都不出膛（即便准星恰好在位）。宽限期内仍继续跟枪（锁在掩体后的 bot 上），这是迟滞的代价，验收 13 补足口径。
12. 正在进行的拉枪在失去可见后带惯性滑行收住，**不是一帧急停**（角速度按指数衰减收住，肉眼可见余势）。
13. 短暂遮挡（连续不可见不足约 0.1s）不触发滑行，继续跟枪；重新可见后**立即**恢复拉枪、瞄到位再开火（恢复无宽限）。
14. bot 死亡空窗仍为冻结保持（**不滑行**，与「看不见」区别对待）；重生后可见性判定从零重新计。
15. 开火门控优先级：死亡 > 看不见 > 看得见——死亡与看不见两种情形均恒不开火。
